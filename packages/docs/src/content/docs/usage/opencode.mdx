# Using ralph with OpenCode

OpenCode is an open-source AI coding assistant. ralph supports OpenCode as a first-class adapter.

## Setup

<Steps>

1. **Install OpenCode**

   ```bash
   go install github.com/opencode-ai/opencode@latest
   ```

   Or download from [releases](https://github.com/opencode-ai/opencode/releases).

2. **Configure your provider**

   OpenCode supports multiple AI providers. Set your preferred one:

   ```bash
   # For Anthropic Claude
   export ANTHROPIC_API_KEY="sk-ant-..."

   # For OpenAI
   export OPENAI_API_KEY="sk-..."
   ```

3. **Verify installation**

   ```bash
   opencode --version
   ```

</Steps>

## Configuration

Set OpenCode as your adapter in `.ralph/config.toml`:

```toml
adapter = "opencode"
```

Provider and model selection is handled through OpenCode's own configuration, not ralph.

## Prompt Patterns

### Standard Pattern

Works the same as Claude Code:

```markdown
# Task

Add error handling to all API routes.

## Guidelines
- Use try/catch for async functions
- Return appropriate HTTP status codes
- Log errors with context

## Verification
Run `npm run lint` - no unhandled promise rejections.

## Progress
Check progress.txt for completed routes.

## Completion
When all routes have error handling, output:
<promise>COMPLETE</promise>
```

## Comparison: OpenCode vs Claude Code

| Feature | OpenCode | Claude Code |
|---------|----------|-------------|
| Provider options | Multiple (Anthropic, OpenAI, etc.) | Anthropic only |
| Open source | Yes | No |
| Cost | Varies by provider | Anthropic pricing |

## Troubleshooting

### "Provider not configured"

Ensure environment variables are set:

```bash
echo $ANTHROPIC_API_KEY  # Should show key
# or
echo $OPENAI_API_KEY
```

### "Model not found"

Check OpenCode's documentation for available models with your provider.

<Aside type="tip" title="Completion Marker">
ralph detects completion when the AI outputs `<promise>COMPLETE</promise>`. Always include this in your prompt's completion instructions.
</Aside>
