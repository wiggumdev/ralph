# Installation

ralph is distributed as an npm package and works on macOS, Linux, and Windows (via WSL).

## Prerequisites

Before installing ralph, ensure you have:

- **Node.js 18+** — ralph uses modern JavaScript features
- **An AI CLI tool** — Claude Code or OpenCode
- **Git** — For state persistence between iterations

<Aside type="note">
ralph orchestrates other AI tools—it doesn't include an AI model itself. You'll need at least one AI CLI tool installed.
</Aside>

## Install ralph

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install -g @wiggumdev/ralph
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add -g @wiggumdev/ralph
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn global add @wiggumdev/ralph
    ```
  </TabItem>
  <TabItem label="bun">
    ```bash
    bun add -g @wiggumdev/ralph
    ```
  </TabItem>
</Tabs>

Verify the installation:

```bash
ralph --version
```

## Install an AI Tool

ralph needs an AI CLI tool to orchestrate. Here are the supported options:

### Claude Code (Recommended)

Anthropic's official CLI for Claude:

```bash
npm install -g @anthropic-ai/claude-code
```

Set your API key:

```bash
export ANTHROPIC_API_KEY="your-key-here"
```

### OpenCode

Open-source AI coding assistant with multi-provider support:

```bash
go install github.com/opencode-ai/opencode@latest
```

### Gemini CLI (Under Development)

Support for Gemini CLI is under development.

## Configuration

<Steps>

1. **Initialize ralph in your project**

   Navigate to your project directory and run:

   ```bash
   cd your-project
   ralph init
   ```

   This creates `.ralph/config.toml` and the `.plans/` directory.

2. **Configure your adapter**

   Edit `.ralph/config.toml`:

   ```toml
   adapter = "claude"
   maxIterations = 10
   ```

3. **Create your task prompt**

   Edit `.plans/PROMPT.md` with your task:

   ```markdown
   # Task

   Add unit tests for all functions in the `src/utils/` directory.

   ## Requirements
   - Each function should have at least 3 test cases
   - Cover edge cases and error conditions
   - Use the existing Jest setup

   ## Progress
   Check progress.txt for completed work.

   ## Completion
   When all functions are tested, output:
   <promise>COMPLETE</promise>
   ```

</Steps>

## Troubleshooting

### "Command not found: ralph"

Ensure npm's global bin directory is in your PATH:

```bash
export PATH="$PATH:$(npm config get prefix)/bin"
```

### "AI tool not found"

Make sure your AI tool is installed and accessible:

```bash
which claude  # or: which opencode
```

### Permission errors

On macOS/Linux, you may need to fix npm permissions:

```bash
mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
export PATH="$PATH:$HOME/.npm-global/bin"
```
